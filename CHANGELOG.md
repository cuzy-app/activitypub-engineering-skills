# Changelog

## 0.2.0 - 2026-10-20

- Merge the HumHub engineering skill into this one: ten `humhub-*` references (module
  structure, Yii2, migrations, content, permissions and events, UI assets, queue jobs,
  tests, coding standards), `scripts/validate_module.py`, the example module and its
  tests, and a PHP syntax CI job. The router has an ActivityPub and a HumHub section;
